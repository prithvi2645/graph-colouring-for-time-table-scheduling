✦ What It Does

A real solution to a real problem

University timetabling is an NP-hard problem. Graph coloring is the elegant theoretical solution.

🧠

Auto Conflict Detection

Just add subjects, assign teachers, and define class divisions. The system builds the conflict graph automatically — no manual edge entry.

🎨

Greedy Graph Coloring

Assigns the minimum number of time slots needed so that no two conflicting subjects share the same slot. Provably optimal coloring approach.

Timetable Generator

📚 Theory

Graph Coloring Explained

The mathematical foundation behind this project.

⚪

Vertices (Nodes)

Each subject is a vertex in the graph. e.g., Mathematics, Physics, Chemistry are all vertices.

↔️

Edges (Conflicts)

An edge connects two subjects that conflict — share a teacher or a student group. They cannot be in the same slot.

🎨

Colors = Slots

Each color = one time slot. Two adjacent nodes must have different colors — two conflicting subjects must be in different slots.

🏆

Chromatic Number

The minimum number of colors needed is the chromatic number χ(G). Greedy gives a near-optimal result in O(V²) time.

⚡

Greedy Algorithm

For each vertex: look at neighbors' colors → assign the smallest unused color. Simple, fast, and effective.

🎓

Real-World Use

Used in university scheduling, exam timetabling, register allocation in compilers, and radio frequency assignment.
